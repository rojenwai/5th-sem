## When you upload material

Drop the files into [`source/`](source/) and the notes will be written into [`notes/`](notes/), following the same structure as the other subjects:

```
OS/
├── README.md     ← this file: syllabus, chapter index, revision checklist
├── notes/        ← one markdown file per chapter
└── source/       ← your original PDFs / DOCX / PPTX, untouched
```

**Most useful thing to upload first:** the **mid-term syllabus**. For the other subjects it determined exactly which topics were in scope — Data Communication had 13 chapters written to its three syllabus units, and three large PDFs were correctly excluded as out of syllabus. Without it, scope has to be guessed from whatever lectures happen to be present (which is what happened with Software Engineering).
