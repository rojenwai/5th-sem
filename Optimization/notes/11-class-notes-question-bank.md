> **Why this chapter exists:** the teacher **sets exam questions from the class notes**, and said: *"For the Simplex Method and Revised Simplex Method portion, study **only from the class notes**."* This chapter collects **every example, question and practice problem in Class Notes 1–5**, in the order they appear, each with its answer.
>
> - Every simplex, Big-M and revised-simplex table below was **generated by a script that follows the class's rules** and checked against the teacher's printed answer. Every one matches.
> - Graphical and duality answers were checked with an LP solver.
> - Where an example is already worked in full in another chapter, you get the question, the answer and a link.
> - Problems the notes **state but never solve** (Big-M Ex 2 and duality Practice Problems 1–4) are marked 🆕 and solved here. They are the likeliest "fresh" exam questions.

**The class's rules** (Class Notes III), used in every table:
- **Entering variable:** largest positive $\Delta_j = c_j - c_B^T Y_j$.
- **Leaving variable:** minimum ratio $x_{Bi}/y_{ik}$ over rows with $y_{ik} > 0$.
- **Stop** when every $\Delta_j \le 0$.
- **Minimisation:** maximise $Z' = -Z$, then $Z_{\min} = -Z'_{\max}$.

**How to read the tables:** ↑ marks the entering column and ← the leaving row. The bottom row gives each $\Delta_j$, with the current $Z$ in the $x_B$ column.

### A2. Example 1 — the shopkeeper (formulation)

*Product A earns Rs. 50 and needs 2 h labour + 1 kg raw material. Product B earns Rs. 40 and needs 1 h labour + 2 kg. There are 100 h of labour and 80 kg of material. Maximise profit.*

Let $x$, $y$ = units of A and B.

$$\text{Max } Z = 50x + 40y \quad \text{s.t.} \quad 2x + y \le 100 \ \text{(labour)}, \quad x + 2y \le 80 \ \text{(material)}, \quad x, y \ge 0$$

### A3. Example 2 — the diet problem (formulation)

| Vitamin | Milk (litre) | Vegetables (kg) | Eggs (dozen) | Minimum daily requirement |
|---|---|---|---|---|
| A | 1 | 1 | 10 | 1 mg |
| B | 100 | 10 | 10 | 50 mg |
| C | 10 | 100 | 10 | 10 mg |
| **Cost (Rs./unit)** | 20 | 10 | 8 | |

Let $x_1$ = litres of milk, $x_2$ = kg of vegetables, $x_3$ = dozens of eggs per day.

$$
\begin{aligned}
\text{Min } Z &= 20x_1 + 10x_2 + 8x_3 \\
\text{s.t. } x_1 + x_2 + 10x_3 &\ge 1 \\
100x_1 + 10x_2 + 10x_3 &\ge 50 \\
10x_1 + 100x_2 + 10x_3 &\ge 10 \\
x_1, x_2, x_3 &\ge 0
\end{aligned}
$$

> 📌 **Requirements → $\ge$**, **cost → Min**. Resource limits → $\le$, profit → Max.

### A6. Example 6 — basic solutions of $x_1 + x_2 + x_3 = 4$, $2x_1 + x_2 + 3x_3 = 7$

$m = 2$, $n = 3$, so each basic solution has one variable set to zero.
- $x_3 = 0$: $x_1 + x_2 = 4$, $2x_1 + x_2 = 7$ gives $x_1 = 3$, $x_2 = 1$ → **(3, 1, 0)**.
- $x_2 = 0$: $x_1 + x_3 = 4$, $2x_1 + 3x_3 = 7$ gives $x_1 = 5$, $x_3 = -1$ → **(5, 0, −1)**. This is basic but **not feasible**.

→ [Ch. 3 §5](03-basic-solutions-and-bfs.md)

### A7. Example 7 — a BFS of $x_1 + x_2 + x_3 = 4$, $2x_1 + x_2 + x_4 = 5$

$m = 2$, $n = 4$, so at least 2 variables are zero. Put $x_3 = x_4 = 0$: $x_1 + x_2 = 4$, $2x_1 + x_2 = 5$ gives $x_1 = 1$, $x_2 = 3$.
**(1, 3, 0, 0)** is a **non-degenerate BFS**: its basic variables $x_1$, $x_2$ are both positive.

### A8. Example 8 — all basic solutions of $x_1 + 2x_2 + x_3 = 4$, $2x_1 + x_2 + 5x_3 = 5$ ⭐

$\binom{3}{2} = 3$ choices of basis:

| Basic variables | $B$ | $\det B$ | $B^{-1}$ | $x_B = B^{-1}b$ | Basic solution |
|---|---|---|---|---|---|
| $x_1, x_2$ | $\begin{bmatrix}1&2\\2&1\end{bmatrix}$ | −3 | $\frac{1}{-3}\begin{bmatrix}1&-2\\-2&1\end{bmatrix}$ | (2, 1) | **(2, 1, 0)** ✅ BFS |
| $x_1, x_3$ | $\begin{bmatrix}1&1\\2&5\end{bmatrix}$ | 3 | $\frac13\begin{bmatrix}5&-1\\-2&1\end{bmatrix}$ | (5, −1) | **(5, 0, −1)** ❌ not feasible |
| $x_2, x_3$ | $\begin{bmatrix}2&1\\1&5\end{bmatrix}$ | 9 | $\frac19\begin{bmatrix}5&-1\\-1&2\end{bmatrix}$ | (5/3, 2/3) | **(0, 5/3, 2/3)** ✅ BFS |

No basic variable is zero in any of them, so **all three are non-degenerate**. → [Ch. 3 §7](03-basic-solutions-and-bfs.md)

### A9. Example 9 — show that $(1, 0, 1)$ with $Z = 6$ is not a basic solution

*Min $Z = 2x_1 + 3x_2 + 4x_3$ s.t. $x_1 + x_2 + x_3 = 2$, $x_1 - x_2 + x_3 = 2$, $x_i \ge 0$.*

1. **Feasible:** $1 + 0 + 1 = 2$ ✓, $1 - 0 + 1 = 2$ ✓, all $\ge 0$ ✓. $Z = 2 + 0 + 4 = 6$.
2. **Basic?** The non-zero variables are $x_1$ and $x_3$, so $B = [\alpha_1, \alpha_3] = \begin{bmatrix}1&1\\1&1\end{bmatrix}$ and $\det B = 1 - 1 = 0$.
3. $B$ is **singular**: the columns of the non-zero variables are **linearly dependent**, so they cannot form a basis.

**∴ $(1, 0, 1)$ is feasible but not a basic solution.**

### A10. Example 10 — is $(1, \tfrac12, 0, 0, 0)$ a basic solution?

*System: $x_1 + 2x_2 + x_3 + x_4 = 2$, $x_1 + 2x_2 + x_4 + x_5 = 2$.*

1. It **satisfies** both equations: $1 + 2(\tfrac12) = 2$ ✓ each.
2. The non-zero variables are $x_1$ and $x_2$, so $B = \begin{bmatrix}1&2\\1&2\end{bmatrix}$ and $\det B = 2 - 2 = 0$. This is **singular**.

**∴ Not a basic solution:** the columns of $x_1$ and $x_2$ are linearly dependent ($\alpha_2 = 2\alpha_1$).

> 💡 **Test for "is this a basic solution?"**: take the columns of the **non-zero** variables. If there are more than $m$ of them, or they are linearly dependent ($\det = 0$), the answer is **no**.

## Part B — Class Note II: slack, surplus, BFS, reducing F.S. → B.F.S.

### B1. Slack and surplus examples

- Max $Z = 2x_1 + 3x_2 + 4x_3$ s.t. $x_1 + x_2 + x_3 \le b_1$, $2x_1 + 4x_2 - x_3 \le b_2$
  → $x_1 + x_2 + x_3 + x_4 = b_1$ and $2x_1 + 4x_2 - x_3 + x_5 = b_2$. **$x_4$, $x_5$ are slack.**
- Max $Z = 2x_1 + 4x_2 + 4x_3$ s.t. $x_1 + x_2 + 2x_3 \le b_1$, $2x_1 + 4x_2 + 6x_3 \ge b_2$, $x_1 - 2x_2 + 4x_3 \ge b_3$
  → $\ldots + x_4 = b_1$, $\ldots - x_5 = b_2$, $\ldots - x_6 = b_3$. **$x_4$ is slack; $x_5$, $x_6$ are surplus.**

**Rule:** $\le$ → **+ slack**; $\ge$ → **− surplus**. → [Ch. 5](05-standard-form-slack-surplus.md)

### B2. Example 1 — finding a BFS of $x_1 + x_2 + x_3 = 4$, $2x_1 + x_2 + x_3 = 5$

Take $B = \begin{bmatrix}1&1\\2&1\end{bmatrix}$ (columns 1 and 2): $\det B = -1 \ne 0$, $B^{-1} = \begin{bmatrix}-1&1\\2&-1\end{bmatrix}$. With $x_3 = 0$:

$$x_B = B^{-1}\begin{bmatrix}4\\5\end{bmatrix} = \begin{bmatrix}1\\3\end{bmatrix} \ \Rightarrow\ \boxed{(1, 3, 0)} \text{ is a B.F.S.}$$

**Procedure:** choose basis → set non-basic variables to 0 → $x_B = B^{-1}b$ → check $x_B \ge 0$.

### The reduction method (used in B3–B6) ⭐⭐

Given a feasible solution with **more than $m$ positive variables**:
1. Write $\sum x_i\alpha_i = b$ using the given values.
2. Find a dependence relation $\sum \lambda_i\alpha_i = 0$ among the columns of the positive variables.
3. Compute $\nu = \max_i (\lambda_i / x_i)$. **The variable achieving the maximum is set to zero.**
4. Eliminate that column between the two equations and read off the new values. Check that they are $\ge 0$ and that the remaining columns are independent.

→ Theory in [Ch. 3 §8](03-basic-solutions-and-bfs.md)

### B3. Example 2 — reduce $(2, 3, 1)$ to a BFS

*System: $2x_1 + x_2 + 4x_3 = 11$, $3x_1 + x_2 + 5x_3 = 14$ (objective max $Z = x_1 + 2x_2 + 4x_3$).*

- $\alpha_1 = \begin{bmatrix}2\\3\end{bmatrix}$, $\alpha_2 = \begin{bmatrix}1\\1\end{bmatrix}$, $\alpha_3 = \begin{bmatrix}4\\5\end{bmatrix}$, and $2\alpha_1 + 3\alpha_2 + \alpha_3 = b$ … (2)
- Write $\alpha_1 = a\alpha_2 + b\alpha_3$: $a + 4b = 2$ and $a + 5b = 3$ give $a = -2$, $b = 1$. So $\alpha_1 + 2\alpha_2 - \alpha_3 = 0$, i.e. $\lambda = (1, 2, -1)$.
- $\nu = \max(\tfrac12, \tfrac23, -1) = \tfrac23 = \lambda_2/x_2$, so **$x_2 = 0$**.
- Eliminate $\alpha_2 = -\tfrac12(\alpha_1 - \alpha_3)$ from (2): $2\alpha_1 - \tfrac32(\alpha_1 - \alpha_3) + \alpha_3 = b$, i.e. $\tfrac12\alpha_1 + \tfrac52\alpha_3 = b$.

$$\boxed{x_1 = \tfrac12, \quad x_2 = 0, \quad x_3 = \tfrac52} \qquad |\alpha_1\ \alpha_3| = \begin{vmatrix}2&4\\3&5\end{vmatrix} = -2 \ne 0 \ \Rightarrow\ \text{B.F.S.}$$

**Check:** $2(\tfrac12) + 4(\tfrac52) = 11$ ✓, $3(\tfrac12) + 5(\tfrac52) = 14$ ✓.

### B4. Example 3 — reduce $(1, 2, 1, 3)$ to a BFS (3 equations, 4 variables)

*System: $5x_1 - 4x_2 + 3x_3 + x_4 = 3$, $2x_1 + x_2 + 5x_3 - 3x_4 = 0$, $x_1 + 6x_2 - 4x_3 + 2x_4 = 15$.*

- $\alpha_1 + 2\alpha_2 + \alpha_3 + 3\alpha_4 = b$ … (2). Four vectors in $\mathbb{R}^3$ are always dependent.
- Write $\alpha_1 = a\alpha_2 + b\alpha_3 + c\alpha_4$: $-4a + 3b + c = 5$, $a + 5b - 3c = 2$, $6a - 4b + 2c = 1$, giving $a = \tfrac{22}{43}$, $b = \tfrac{139}{86}$, $c = \tfrac{189}{86}$.
- Multiply by 86: $86\alpha_1 - 44\alpha_2 - 139\alpha_3 - 189\alpha_4 = 0$, so $\lambda = (86, -44, -139, -189)$.
- $\nu = \max(86, -22, -139, -63) = 86 = \lambda_1/x_1$, so **$x_1 = 0$**.
- Substitute $\alpha_1 = \tfrac{44\alpha_2 + 139\alpha_3 + 189\alpha_4}{86}$ into (2).

$$\boxed{\left(0,\ \tfrac{216}{86},\ \tfrac{225}{86},\ \tfrac{447}{86}\right) = \left(0,\ \tfrac{108}{43},\ \tfrac{225}{86},\ \tfrac{447}{86}\right)}$$

This is a B.F.S.: the columns $\alpha_2, \alpha_3, \alpha_4$ are independent. **Verified:** it gives exactly $b = (3, 0, 15)$.

### B5. Question 3 = Example 5 — reduce $(2, 4, 5)$ to a BFS ⭐

*System: $2x_1 - x_2 + 2x_3 = 10$, $x_1 + 4x_2 = 18$.*

$\alpha_1 = \begin{bmatrix}2\\1\end{bmatrix}$, $\alpha_2 = \begin{bmatrix}-1\\4\end{bmatrix}$, $\alpha_3 = \begin{bmatrix}2\\0\end{bmatrix}$, and $2\alpha_1 + 4\alpha_2 + 5\alpha_3 = b$. Writing $\alpha_1 = a\alpha_2 + b\alpha_3$: $4a = 1$ and $-a + 2b = 2$ give $a = \tfrac14$, $b = \tfrac98$. So

$$8\alpha_1 - 2\alpha_2 - 9\alpha_3 = 0$$

**The class notes solve this same problem twice, getting two different (both correct) B.F.S.:**

| | Question 3 | Example 5 |
|---|---|---|
| Sign of the relation used | $\lambda = (8, -2, -9)$ | multiplied by −1: $\lambda = (-8, 2, 9)$ |
| $\nu = \max(\lambda_i/x_i)$ | $\max(4, -\tfrac12, -\tfrac95) = 4 = \lambda_1/x_1$ | $\max(-4, \tfrac12, \tfrac95) = \tfrac95 = \lambda_3/x_3$ |
| Variable set to zero | $x_1 = 0$ | $x_3 = 0$ |
| Eliminate | $\alpha_1 = \tfrac14\alpha_2 + \tfrac98\alpha_3$ | $\alpha_3 = \tfrac89\alpha_1 - \tfrac29\alpha_2$ |
| **B.F.S.** | $\boxed{\left(0, \tfrac92, \tfrac{29}{4}\right)}$ | $\boxed{\left(\tfrac{58}{9}, \tfrac{26}{9}, 0\right)}$ |
| Check $(2x_1 - x_2 + 2x_3,\ x_1 + 4x_2)$ | $(-\tfrac92 + \tfrac{29}{2},\ 18) = (10, 18)$ ✓ | $(\tfrac{116 - 26}{9},\ \tfrac{58 + 104}{9}) = (10, 18)$ ✓ |

> 💡 **Why two answers?** A dependence relation can be written with either sign. Each sign drives a different variable to zero. In an exam, give **one** answer and verify it; you can mention the other.

### B6. Example 4 = Example 6 — reduce $(1, 1, 1)$ to a BFS

*System: $x_1 + x_2 + 2x_3 = 4$, $2x_1 - x_2 + x_3 = 2$.*

- $\alpha_1 = \begin{bmatrix}1\\2\end{bmatrix}$, $\alpha_2 = \begin{bmatrix}1\\-1\end{bmatrix}$, $\alpha_3 = \begin{bmatrix}2\\1\end{bmatrix}$, and $\alpha_1 + \alpha_2 + \alpha_3 = b$.
- Since $\alpha_1 + \alpha_2 = \alpha_3$, we have $\alpha_1 + \alpha_2 - \alpha_3 = 0$, so $\lambda = (1, 1, -1)$.
- $\nu = \max(1, 1, -1) = 1$. There is a **tie** between $x_1$ and $x_2$.

| Choice | Result |
|---|---|
| $x_1 = 0$: substitute $\alpha_1 = -\alpha_2 + \alpha_3$ | $2\alpha_3 = b$ → **(0, 0, 2)**. Because of the tie, $x_2$ also becomes 0, so this is a **degenerate** B.F.S. |
| Reverse the sign: $-\alpha_1 - \alpha_2 + \alpha_3 = 0$, so $\nu = 1 = \lambda_3/x_3$, $x_3 = 0$ | $\alpha_3 = \alpha_1 + \alpha_2$ gives $2\alpha_1 + 2\alpha_2 = b$ → **(2, 2, 0)**, a non-degenerate B.F.S. |

**Check (2, 2, 0):** $2 + 2 + 0 = 4$ ✓, $4 - 2 + 0 = 2$ ✓. **Both $(0, 0, 2)$ and $(2, 2, 0)$ are B.F.S.**

> 📌 **A tie in $\nu$ produces a degenerate B.F.S.**, because two variables vanish at once.

## Part C — Class Notes III: Simplex method

### C0. Artificial-variable illustrations (setup)

- **Ex 1 ($\ge$):** $x_1 + 2x_2 \ge 6$ → $x_1 + 2x_2 - s_1 = 6$. Making $s_1$ basic gives $s_1 = -6 < 0$ ✗, so **add $A_1$**: $x_1 + 2x_2 - s_1 + A_1 = 6$, initial $A_1 = 6$.
- **Ex 2 (=):** $x_1 + x_2 \le 4$, $2x_1 + x_2 = 5$ → $x_1 + x_2 + s_1 = 4$, $2x_1 + x_2 + A_2 = 5$. Initial basis $\{s_1, A_2\}$ with $s_1 = 4$, $A_2 = 5$.

**Table 2 (initial B.F.S.):** all $\le$ → $[A \mid I_m]$, slacks $= b_i$ · all $\ge$ → $[A \mid -I_m \mid I_m]$, artificials $= b_i$ · mixed → slacks for $\le$ rows, artificials (or existing unit columns) for the rest.

## Part E — Class Note 5: Duality

### E1. Examples 1–4 (solved in the notes)

| Example | Primal | Key point | Where |
|---|---|---|---|
| 1 | Min $3x_1 + x_2$ s.t. $2x_1 + 3x_2 \ge 2$, $x_1 + x_2 \ge 1$ | Standard minimisation → dual is Max with $\le$ | [Ch. 9 §5](09-duality.md) |
| 2 | Max $2x_1 + 3x_2 + x_3$ s.t. two **equalities** | Equality constraint → **unrestricted** dual variable | [Ch. 9](09-duality.md) |
| 3 | Min $2x_2 + 5x_3$ s.t. $\ge$, $\le$, $=$ (mixed) | Convert everything to $\ge$; split the equality into two | [Ch. 9](09-duality.md) |
| 4 | Min $x_1 + x_2 + x_3$ with **$x_3$ unrestricted** | Unrestricted primal variable → **equality** dual constraint | [Ch. 9 §8](09-duality.md) |

**The rules the class uses:**
- **Max** primal: write every constraint as $\le$ → the dual is **Min** with $\ge$ constraints.
- **Min** primal: write every constraint as $\ge$ → the dual is **Max** with $\le$ constraints.
- The dual's objective coefficients are the primal's RHS. The dual's RHS values are the primal's objective coefficients. The coefficient matrix is **transposed**.
- A primal **equality** gives an **unrestricted** dual variable. An **unrestricted** primal variable gives an **equality** dual constraint.

### E2. Practice Problem 1 🆕

*Max $Z = x_1 + 2x_2$ s.t. $2x_1 - 3x_2 \le 3$, $4x_1 + x_2 \le -4$, $x_1, x_2 \ge 0$.*

Both constraints are already $\le$, so assign $w_1, w_2 \ge 0$:

$$\boxed{\text{Min } Z_D = 3w_1 - 4w_2 \quad \text{s.t.} \quad 2w_1 + 4w_2 \ge 1, \quad -3w_1 + w_2 \ge 2, \quad w_1, w_2 \ge 0}$$

> 💡 **Worth noticing:** with $x_1, x_2 \ge 0$, $4x_1 + x_2 \ge 0 > -4$, so the **primal is infeasible**. Its dual is **unbounded**: taking $w_2 = 2 + 3w_1$ and letting $w_1 \to \infty$ makes $Z_D \to -\infty$. Infeasible primal with unbounded dual is one of the cases of the duality theorem. Do **not** multiply the second constraint by −1 before writing the dual; a max primal keeps its $\le$ form.

### E3. Practice Problem 2 🆕

*Min $Z = 4x_1 + 6x_2 + 18x_3$ s.t. $x_1 + 3x_3 \ge 3$, $x_2 + 2x_3 \ge 5$, $x_1, x_2, x_3 \ge 0$.*

This is standard minimisation (all $\ge$). With $w_1, w_2 \ge 0$ and $A^T$ (columns $(1, 0)$, $(0, 1)$, $(3, 2)$):

$$\boxed{\text{Max } Z_D = 3w_1 + 5w_2 \quad \text{s.t.} \quad w_1 \le 4, \quad w_2 \le 6, \quad 3w_1 + 2w_2 \le 18, \quad w_1, w_2 \ge 0}$$

**Check by solving:** the dual optimum is $w = (2, 6)$, $Z_D = 36$, and the primal optimum is $x = (0, 3, 1)$, $Z_P = 36$. $Z_P = Z_D$ ✓, as the duality theorem says.

### E4. Practice Problem 3 🆕

*Max $Z = x_1 + 3x_2$ s.t. $3x_1 + 2x_2 \le 6$, $3x_1 + x_2 = 4$, $x_1, x_2 \ge 0$.*

Constraint 1 ($\le$) gets $w_1 \ge 0$. Constraint 2 is an **equality**, so $w_2$ is **unrestricted**.

$$\boxed{\text{Min } Z_D = 6w_1 + 4w_2 \quad \text{s.t.} \quad 3w_1 + 3w_2 \ge 1, \quad 2w_1 + w_2 \ge 3, \quad w_1 \ge 0, \ w_2 \text{ unrestricted}}$$

**Check:** primal optimum $x = (\tfrac23, 2)$, $Z_P = \tfrac{20}{3}$. Dual optimum $w = (\tfrac83, -\tfrac73)$, $Z_D = 16 - \tfrac{28}{3} = \tfrac{20}{3}$ ✓. Note $w_2 < 0$, which is allowed because $w_2$ is unrestricted.

### E5. Practice Problem 4 🆕

*Max $Z = 3x_1 + 5x_2 + 4x_3$ s.t. $2x_1 + 3x_2 \le 8$, $2x_2 + 5x_3 \le 10$, $3x_1 + 2x_2 + 4x_3 \le 15$, $x_i \ge 0$.*

$$\boxed{
\begin{aligned}
\text{Min } Z_D &= 8w_1 + 10w_2 + 15w_3 \\
\text{s.t. } 2w_1 + 3w_3 &\ge 3 \\
3w_1 + 2w_2 + 2w_3 &\ge 5 \\
5w_2 + 4w_3 &\ge 4 \\
w_1, w_2, w_3 &\ge 0
\end{aligned}}
$$

> ⭐ **Link to Simplex Example 2 (C2).** This primal *is* C2, whose optimum is $\tfrac{765}{41}$. By the duality theorem, $\min Z_D = \tfrac{765}{41}$ too. The optimal dual values are $w = (\tfrac{45}{41}, \tfrac{24}{41}, \tfrac{11}{41})$, which are exactly **minus the $\Delta_j$ of the slack columns** $x_4, x_5, x_6$ in C2's final table ($-\tfrac{45}{41}, -\tfrac{24}{41}, -\tfrac{11}{41}$). You can read the dual solution straight off the optimal primal simplex table.
